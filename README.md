# Waynote - найди маршрут своей мечты

Автор: Куркин Тимофей Павлович

## Как запустить?

```console
npm i
npm run start
```

## Какие проблемы?

- Велосипедисты хотят катать безопасные, красивые и интересные маршруты
- Было бы круто хранить маршруты в универсальном формате с максимальной точностью
- Нужно единое место, где можно обмениваться маршрутами с другими велосипедистами

## Решение

- Веб-приложение для хранения и обмена маршрутам
- Возможность скачать маршрут в универсальном GPX-формате.
- Визуализация маршрута прямо на интерактивной карте – сразу поймешь куда едешь

## Трудности

- Землю нельзя просто так «расположить» на плоскости
    - Карты, построенные по проекции Меркатора, искажают объекты у полюсов
- Пришлось решить две задачи
    - Приведение координат к единой системе, для определения границ маршрута
    - Уменьшение количества точек с помощью алгоритма Ramer–Douglas–Peucker для создания «статичной» карты
- В итоге, маршруты отображаются корректно и быстро
